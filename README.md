🎒 Campus Lost & Found Portal

A modern full-stack web app to manage lost and found items on campus, built with React.js, FastAPI, and MongoDB.

✨ Key Features

JWT Authentication: Secure login & registration

Post & Browse Items: Filter by category, location, date, and status

Smart Matching: AI-based suggestions for lost/found items

Image Uploads: Optimized drag-and-drop uploads

Responsive UI: Clean, mobile-friendly design with Tailwind CSS

Real-time Feedback: Toast notifications and loading states

🛠 Tech Stack

Frontend: React 18, Vite, Tailwind CSS

Backend: FastAPI, Python, JWT, Motor

Database: MongoDB

Deployment: Vercel (Frontend), Railway/Heroku (Backend)

🚀 Highlights

RESTful APIs with strong security

Accessible, modern UI

Scalable architecture

Production-ready setup

Made for campus communities to quickly reunite people with their lost belongings. ❤️
